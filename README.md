# Empire login
A simple website made to similuate a login using **localStorage**. Orinally using nothing more than pure JavaScript, CSS, and HTML, it is currently made with React.JS, and Next.JS

To run it, you simply need to install Node.JS and run the following command to install all the dependencies

```shell
  npm install 
  ```

Afterwards, you can run the command ` npm run dev ` in order to run the app.
